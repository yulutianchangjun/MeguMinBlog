## 惠惠主题个人博客：从说明书到可交付实现

- 输入：`个人博客系统架构与需求设计说明书.md` + `meguminUI/slices/`（111 个素材）。
- 技术栈：Vue 3.5 + TS + Vite 6 + Pinia 2 + Vue Router 4（Hash 模式）+ Naive UI 2（仅配置/弹窗/抽屉/确认框）+ markdown-it + highlight.js + JSZip。纯静态，无后端。
- 目录约定：
  - `content/posts/*.md`（Frontmatter 由自写极简 YAML 解析器 `src/lib/frontmatter.ts` 处理，避免 Buffer polyfill）、`content/collections.json`。
  - `src/styles/{tokens,base,prose}.css` 承载调色板与通用视觉；组件样式 scoped。
  - 状态：`stores/{auth,content,interaction,profile,reading,ui}.ts`；`content` 用「种子 + overlay」模型（created/updated/deleted），管理面板的增删改只动 overlay。
  - 持久化：localStorage 前缀 `mgm:`；PAT 会话存 sessionStorage。
- 关键实现点（后续维护注意）：
  - 图片落在 `public/assets/megumin/`（从中文切片重命名），Markdown 内写 `assets/megumin/xxx.png`。因 `base: './'` + hash 路由，引用统一 `./` 前缀即可，子路由不会断图。
  - 切片原图为浅粉底，暗色主题下统一用「暗红底 + img `mix-blend-mode: multiply` + brightness≈1.2」做双色调，否则白底矩形非常刺眼。
  - 列表状态：筛选/页码同步 URL Query + `<KeepAlive include="PostsView">` + 组件内存里的 savedScroll，返回时还原滚动；列表查询同时写 `sessionStorage['mgm:last-list-query']`，详情页「返回列表」优先复原。
  - 右侧栏按路由切换：`route.name === 'post'` → 目录（滚动 spy + 阅读进度），否则日历 + 纪念日。TOC 数据经 `stores/reading.ts` 共享。
  - 留言墙按「墙 → 每 5 张一批」chunk，新卡进入最新批次；三面墙的最新批次都满时自动开新批次。
  - 音乐播放器无音频文件，用 Web Audio 合成长度 32 步的循环（`src/lib/chime.ts`），首次点击才创建 AudioContext。
- 踩坑：Pinia 的 `ref(obj)` 会被包成 reactive proxy，`structuredClone` 会抛 DataCloneError，导致管理面板「保存/置顶/隐藏」静默失败；改为 JSON 深拷贝 `clone()` 后恢复。首轮截图没发现，是用 Playwright 端到端点「新建手记」才暴露。
- 验证：`npm run typecheck` + `npm run build` 通过；Playwright 覆盖 16 项流程（筛选/搜索/分页/返回保状态/TOC 高亮/访客评论与权限/暗门登录/盖楼/发卡/新建文章/隐藏不可见）全部 PASS，控制台无报错；生产预览下图片与 hash 路由正常。
- 部署：`.github/workflows/deploy.yml`（npm ci → typecheck → build → upload-pages-artifact → deploy-pages），Pages Source 选 GitHub Actions 即可。
- 管理入口：连点头像 5 次 / `Ctrl+Shift+L`；离线口令默认 `explosion`（`src/data/site.ts` 可改，`admin.githubLogin` 配置后 PAT 需匹配该账号）。
- 已清理：临时截图脚本与 Playwright 依赖已删除，仓库只保留业务代码与 README。
