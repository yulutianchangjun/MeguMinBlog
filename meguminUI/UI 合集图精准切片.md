# 惠惠主题 UI 合集图 · 精准切片说明

从 5 张合集长图中逐块切出的 **111** 个可直接使用的素材文件，按「母版图」分包存放。

## 一、方法

合集图是浅色底、无坐标标注的画板，直接目测坐标误差可达 90px。因此切片用「自动量测 + 边界吸附」的流程完成：

1. **面板量测**：以页面底色为模板做行/列投影，找出只有底色的空白行与空白列，得到每块面板的真实边界（像素级）。
2. **主体吸附**：按量测框裁切后，从四边向内收缩到「非底色」的第一个像素，去掉四周留白，边缘贴合。
3. **去底透明**：对图标、按钮、贴纸这类四周被纯色包围的元件，从边缘泛洪填充为透明通道——只去掉外部底色，元件内部的白色高光得以保留。
4. **目视复核**：每个分包生成一张预览图逐块检查，是否切到主体、是否带进邻块碎片，累计修正 30 余处坐标后定稿。

## 二、目录结构

```
slices/
  01-组件图鉴/  —  35 个切片
  02-角色主题UI素材包/  —  20 个切片
  03-角色与游戏UI素材表/  —  22 个切片
  04-魔法界面素材集/  —  14 个切片
  05-贴纸素材板/  —  20 个切片
    每包内含：00-预览.jpg（缩略预览） / *.png（切片） / _manifest.json（清单）
_slice/           重切工具与配置（cfg_all.json + slicer.py）
```

`_manifest.json` 每条记录含 `name`、`file`、`size`、`abs`（源图坐标 `[x, y, w, h]`）、`alpha`（是否带透明通道）、`note`。需要回溯源位置、换分辨率或接入设计系统时，直接读这个文件。

## 四、命名规则

`序号-类型-名称.png`，例如 `24-card-爆裂魔法.png`。

| 类型段 | 含义 | 常见用法 |
|---|---|---|
| `panel` | 成组面板 | 整块当区块/卡片底 |
| `block` | 素材区块 | 一组同主题素材（多角色、多状态） |
| `grid` | 规则网格 | 3×2 表情头像，可按格再分 |
| `card` | 单张卡片 | 独立卡片组件 |
| `btn` | 按钮 | 主/次/图标按钮 |
| `elem` | 元件 | 输入框、开关、复选、下拉、进度条 |
| `icon` | 图标 | 导航、头像、黑猫、装饰图标 |
| `tag` | 标签徽章 | 药丸标签 |
| `art` | 插画 / 特效 | 立绘、魔法阵、火焰、烟雾 |
| `bubble` | 气泡 | 台词 / 提示气泡 |

## 五、使用提示

- **两种底**：标「透明 是」的是 RGBA，可直接叠在任意背景上；标「—」的是原图裁切，内含画板浅粉卡底，适合整块当卡片用。
- **表单输入框（01 包 14/15/16）刻意保留原底**：这类控件的描边与卡底同色系，强行抠透明会把边框一起抠掉，留底反而更完整。
- **尺寸是原始像素**，未缩放。做 2x/3x 请用原图重新导出，不要放大位图。
- **网格可再分**：`grid` 类为 3×2 等分布局，需要单张头像时按 `w/3`、`h/2` 再切，缝隙已对齐。
- **想重切**：改 `_slice/cfg_all.json` 对应条目的 `b`（源坐标）后运行
  `python _slice/slicer.py all _slice/cfg_all.json`，全量重出。
