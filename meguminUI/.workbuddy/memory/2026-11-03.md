## 惠惠主题 UI 合集图精准切片

- 任务来源：`UI 合集图精准切片.md`（原文件为空），实际需求＝把 5 张 1536×1024 合集长图切成可复用素材。
- 产出：`slices/01..05-*/` 共 111 个 PNG（01 组件图鉴 35、02 素材包 20、03 素材表 22、04 素材集 14、05 贴纸板 20），每包含 `00-预览.jpg` 与 `_manifest.json`（文件名/尺寸/源坐标/是否带 alpha）。
- 文档：`UI 合集图精准切片.md` 记录方法、目录、逐条清单（含源坐标）、命名规则、使用提示。
- 关键技术结论（可复用）：
  - 合集图是浅底画板，目测坐标误差可达 90px，必须量测。用「页面底色模板（取图像边框 ring 的中位数）+ 行/列投影找纯底色空白带」定位面板边界，再对每块做「非底色首像素」收缩，即可像素级贴合。
  - 元件透明化用「从裁切边界泛洪填充同色 → alpha=0」，只去外部底色，保留内部白色高光；若控件描边与卡底同色系（如浅粉输入框），抠透明会连边框一起消失，应保留原底。
  - 仅对四周被纯色包围的裁切件做泛洪（`surrounded` 判定 + 边框 ring 标准差 < 6），否则会把面板整块吃掉。
- 工具保留在 `_slice/`：`slicer.py`（切片+去底+拼预览）、`cropgrid.py`（生成绝对坐标网格放大图用于量测）、`cfg_all.json`（全部源坐标，改 `b` 即可重切）。
